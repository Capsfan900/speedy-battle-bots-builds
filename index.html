Install and play

Download Setup (73 MB)
  1. Run the Setup. It installs for your Windows account only (no admin needed) and adds Start menu and desktop shortcuts.
  2. Windows may say "Windows protected your PC" because this free preview is not code-signed. Click More info, then Run anyway.
  3. A newer Setup later updates in place and keeps your settings. Uninstall from Settings > Apps.
