# Speedy Battle Bots — Windows builds

Playable Windows preview builds of Speedy Battle Bots, for friends and playtesters.
This repository holds **builds only**. The game's source code is private and is not here.

## Download and play

1. Open [Releases](https://github.com/Capsfan900/speedy-battle-bots-builds/releases) and pick the newest one.
2. Download **SpeedyBattleBots-Setup-….exe** and run it. It installs for your Windows account only
   (no admin needed) and adds Start menu and desktop shortcuts. A newer Setup updates in place
   and keeps your settings.
3. Windows may say "Windows protected your PC", because these free previews are not code-signed.
   Click **More info**, then **Run anyway**.

No install: download the **.zip** instead, extract all of it, and run `SpeedyBattleBots.exe`.

**Everyone playing together online must use the same build.**

Each release lists SHA-256 checksums for its files.

**About the "Source code (zip / tar.gz)" links on each release:** GitHub adds them to every release
automatically. For this repository they are an archive of this README and nothing else. The game's
source code is private and is not published anywhere.
